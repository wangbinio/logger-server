# 仓库规则

## 语言和文档

- 对外回复和仓库文档使用简体中文。
- 不使用 emoji、颜文字或类似符号。
- Java 函数声明处需要中文注释，复杂实现逻辑适当添加中文注释。

## 工作流

- 非平凡任务先写 `tasks/todo-XX-描述.md`，包含可勾选计划。
- 实施过程中持续更新任务单，完成后写复盘记录。
- 用户纠正后，必须把可复用模式写入 `tasks/lessons.md`。
- 设计或阶段任务优先读 `plan/`，再读代码。
- 现有 `final.md` 已被用户确认时，通常直接按文档实现和验证，不重新发散方案。

## 代码原则

- 最小影响修改，不做无关重构。
- Java 目标版本为 Java 8，不能引入高版本语言特性。
- 保持现有测试契约，用户要求不改测试时优先从配置、构建或生产代码收敛。
- 不要回滚用户或其他任务已有改动。

## 验证原则

- 默认回归和真实环境测试必须分开表述。
- 默认回归不应依赖外部 RocketMQ/TDengine。
- 真实环境测试必须显式开关执行。
- 涉及 TDengine、RocketMQ、消息码、回放调度和 HTTP 控制时，至少运行对应模块测试；如果用户要求真实环境，则必须运行真实环境测试。
